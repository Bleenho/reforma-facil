# reforma-facil

Marketplace de serviços para imóveis. Por enquanto, só uma página "Reforma Fácil — em breve".

## Comandos

```
npm install
npm run dev         # desenvolvimento em http://localhost:3000
npm run lint        # ESLint
npm run type-check  # TypeScript
npm run build       # build de produção
```

O deploy é feito pelo Dokploy via GitHub; veja [docs/deploy-dokploy.md](docs/deploy-dokploy.md).
